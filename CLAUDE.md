# Presupuestador Pro

App web para que proveedores de servicios independientes argentinos generen presupuestos profesionales en PDF más rápido y presentable, lo que aumenta el valor percibido y el ticket del servicio, y ahorra tiempo en armar presupuestos. Ademas mantiene en tu cuenta el historial y metricas de faturacion. 

## Stack
- HTML + CSS + JS vanilla por ahora, sin frameworks.

## Primera feature
Formulario con:
- Datos del proveedor
- Datos del cliente
- Ítems de servicio (con cantidad y precio unitario)
- Generación de PDF descargable
